# Main Image Analysis Template Skill

A shareable Codex Skill for ecommerce main image analysis.

Use it to analyze product thumbnails, marketplace main images, competitor visuals, and listing hero images from a click-through and conversion perspective.

## What It Produces

- Product and target-user judgment
- First-second visual diagnosis
- Click-reason analysis
- Short main-image headline options
- Composition structure recommendation
- Competitor comparison
- Next-version revision checklist
- A/B test directions
- Reusable template for future products

## Install

Copy this repository folder into your Codex skills directory, or download the files and keep the same structure:

```text
main-image-analysis-template/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── main-image-template.md
```

## Use

Invoke it in Codex with:

```text
Use $main-image-analysis-template to analyze this product main image and produce a reusable improvement template.
```

Recommended inputs:

- Product details
- Current main image or screenshot
- Target marketplace
- Target user
- Competitor images
- Buyer reviews
- Business goal

## Best For

Taobao, Tmall, JD, Pinduoduo, Douyin ecommerce, Amazon, TikTok Shop, Temu, independent stores, and other ecommerce listing workflows.
